# 复试准备框架

## 材料层

- 一页中文简历，所有项目和奖项都能经得住追问；
- 成绩单、排名证明、证书和官方要求材料按清单整理；
- 准备 1 分钟与 3 分钟两个版本的自我介绍；
- 对目标科室和导师方向只引用公开信息，不把群聊传言当事实。

## 专业层

- 以初试专业基础为底，重新梳理数据结构、组成原理、操作系统和计算机网络；
- 能解释本科核心课程中的基本概念，而不是只背名词；
- 针对简历项目准备“目标、个人贡献、关键难点、验证方式、失败复盘”；
- 如果目标科室通知包含机试或笔试，按通知范围单独训练。

## 表达层

回答不知道的问题时，先说明边界，再给出已有理解和推导过程。不要编造论文内容、项目贡献或导师方向。

一次回答可以按以下结构组织：

1. 先给结论；
2. 解释关键依据；
3. 用项目或课程中的例子验证；
4. 主动说明不确定之处。

## 当天检查

- [ ] 设备、电源、网络或线下路线已验证
- [ ] 文件名、证件和纸质材料符合通知要求
- [ ] 简历每一行都能展开说明
- [ ] 目标科室官方简介已重新核对
- [ ] 不携带或传播明确禁止的复试内容
