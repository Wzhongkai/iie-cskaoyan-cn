# 投稿与纠错

本站希望把零散信息变成可追溯、可更新的公共资料。经验不同没有关系，但年份、来源和事实边界必须写清楚。

## 可以提交

- 初试、复试和就业经验；
- 官方招生文件更新；
- 历年数据纠错和口径说明；
- 科室官方页面与导师公开主页更新；
- 页面错别字、失效链接和无障碍问题。

## 投稿格式

```yaml
---
title: 文章标题
year: 2026
category: initial # initial / reexam / career
background: 双非科班
comments: true
source: original
---
```

正文建议包含背景、时间线、具体做法、失败复盘和适用边界。涉及分数时说明总分与单科，涉及就业待遇时说明年份、城市和统计口径。

## 提交方式

1. Fork 仓库并新增 Markdown 文件；
2. 在 `mkdocs.yml` 的导航中加入文章；
3. 本地运行 `mkdocs build --strict`；
4. 提交 Pull Request，并在说明中注明内容来源与授权情况。

不熟悉 GitHub 的投稿者，可以先把文章交给维护者代为整理。发布前仍需要作者确认最终文本。

## 不会收录

- 泄露个人隐私、复试保密内容或群文件访问凭据；
- 无来源的导师评价、录取“内幕”和人身攻击；
- 课程广告、付费咨询导流和伪装投稿；
- 无法说明年份和样本的薪资、录取概率结论。
