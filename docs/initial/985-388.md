# 985 科班初试 388

原作者本科就读于华中科技大学网络空间安全专业，加权成绩约 85.1，专业排名约 60+/100。文章是一篇个人备考流水账，价值在于展示了一个科班考生如何在家庭预算、研究方向和考试难度之间完成择校，并安排四科复习。

## 可复用的信息

- 择校不是只比分数线，还应同时考虑研究方向、培养成本和未来三年生活；
- 数学与 408 需要持续做题，但后期仍要回到教材和错题，避免只追模拟卷数量；
- 408 真题完成后，可以通过回看教材和二刷真题维持知识结构；
- 政治投入相对靠后，英语和政治不能挤占数学、408 的核心时间，但也不能到考前才首次接触；
- 固定日程比临时冲刺更可靠，文章后期大致保持上午数学、下午 408、晚上英语与政治。

## 不应直接照搬的部分

作者是网安科班，专业课基础和课程背景与跨考生不同；使用的课程、教师和模拟卷也有明显个人偏好。阅读时应提炼“何时复盘、如何发现漏洞”，不要把资料名单当作采购清单。
