# 普通双非三无一战上岸

原作者本科为河南某双非一本软件工程专业，排名约前 30%，竞赛和项目经历都不突出。文章的核心不是“逆袭叙事”，而是说明初试准备和复试表达仍然可以通过长期行动改善。

## 可复用的信息

- 英语基础弱时，背词和阅读需要尽早形成每日任务，连续性比单日时长更重要；
- 真题应精做并复盘，不要只记录正确率；
- 数学和 408 的失误常来自浮躁与不仔细，模拟阶段要训练完整考试节奏；
- 政治投入需要控制性价比，不能因为资料焦虑挤压主科；
- 本科背景、竞赛和项目不占优时，更需要把能控制的部分做扎实，并在复试中诚实、清楚地表达已有经历。
