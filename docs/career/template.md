# 就业分享投稿模板

投稿时可以删除不愿公开的字段。涉及公司、导师和同学时，请确认信息已经公开或取得授权。

```markdown
# 标题：届别 + 方向 + 去向类型

## 背景
- 毕业届别：
- 学历：硕士 / 博士
- 研究方向：
- 是否有实习：

## 求职时间线
- 开始准备：
- 投递阶段：
- 最终决定：

## 岗位与选择
- 岗位方向：
- 工作城市：
- 选择时最看重的因素：

## 准备经验
- 简历：
- 笔试：
- 面试：

## 待遇口径（可选）
- 年份与城市：
- 税前 / 税后：
- 基本工资 / 总包：
- 是否包含签字费、股票或补贴：

## 给后来者的建议

## 隐私与授权
- [ ] 内容不包含未授权个人信息
- [ ] 数据口径已经说明
```
